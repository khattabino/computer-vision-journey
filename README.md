# computer-vision-journey
This repository documents my learning journey, from fundamental image operations to more advanced computer vision techniques.

01_basics/
├── io_images.py             # read, show, and save images
├── io_video.py              # read video files
├── io_webcam.py             # live webcam capture
├── resizing.py              # resize images
├── cropping.py              # crop regions of interest
└── drawing.py               # lines, rectangles, circles, text

02_color/
├── coloring.py              # color space conversions
└── color_detection.py       # detect objects by color

03_filtering/
└── blurring.py              # average, Gaussian, median blur

04_thresholding/
├── global_threshold.py
└── adaptive_threshold.py

05_edges_contours/
├── edge_detection.py        # Canny and friends
└── contours.py              # find and draw contours
